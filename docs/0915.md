- **저장 실패 재시도**: 저장 로직을 `performSave`로 분리해 debounce/재시도가 공유, `retrySave(editor)` 노출. `NotionEditor.jsx`에 `saveStatus === 'error'`일 때만 보이는 Retry 버튼 추가.

### P2-2. AI 외부 연동 안정성

- **설정 필수값 검증**: `QuizAiGenerationService.validateConfig()`를 `@PostConstruct`로 추가 — `GEMINI_API_KEY` 없으면 기동 실패.

- **RestTemplate timeout**: connect 5초/read 60초 설정.
- **AI 응답 구조 검증 + 예외 변환**: `candidates`/`parts`/`text` 단계별 검증 후 신규 `ExternalServiceException`(503)으로 통일, `GlobalExceptionHandler`에 핸들러 추가.
