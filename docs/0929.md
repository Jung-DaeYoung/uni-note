## 2. P0 마무리: 요청 제한 통일·schema 강화·생성 메타데이터 로그 (`e88c237`)

`PLANS.md` §6 5번 중 남은 P0-3과 P0-4를 구현했다.

- **요청 제한 통일:** `QuizRequest.typeCounts`를 `@Min(0) @Max(50)`에서 `@Min(1) @Max(20)`으로 바꿔 서비스·프론트와 맞췄다. 이제 0이나 21 이상은 DTO 단계에서 400 `VALIDATION_FAILED`가 된다.
- **Gemini response schema 강화:**
  - `type`·`difficulty`를 enum으로 제한했다. 값은 `QuestionType`·`QuizDifficulty`의 `values()`로 만든다.
  - `explanation`을 필수로 바꿨다.
  - `sourceNoteId`/`sourceBlockId`는 REF가 있는 입력에서만 필수로 한다. 미디어만 있는 입력에서 출처를 강제하면 출처를 지어낼 위험이 있기 때문이다.
  - **prompt 문구는 바꾸지 않았고**, 이를 고정하는 테스트를 추가했다.
- **모델명·prompt 버전 상수화:** `MODEL_NAME`, `PROMPT_VERSION`을 두었다. prompt나 schema를 바꾸면 버전을 올린다.
- **원문 해시:** `QuizGenerationInput.contentHash()`를 추가했다. 텍스트와 미디어 base64를 SHA-256으로 해시한다.
- **생성 결과 로그:** 요청당 `quiz.generation status=… model=… promptVersion=… contentHash=… attempts=… regenerated=… unverified=… elapsedMs=… failureCode=… failureReason=… quizSetId=… studId=…` 한 줄을 남긴다.
  - 노트 본문과 학번은 넣지 않는다.
  - 저장 단계 실패도 `STORAGE_ERROR`로 기록한다. 응답은 기존 그대로다.
- backend 테스트는 226건이 통과했다.

## 4. 블록 단위 문제 범위 선택 P1-5 (`394debb`)

- 추출 로직: `extractDataFromNode`에 `inScope`를 추가했다.
  - 선택한 블록과 그 하위만 텍스트·REF·미디어를 넣는다.

## 5. 여러 노트에서 블록 선택 + 빈 블록 제외 (`c70b200`)

사용자 피드백("현재 노트의 블록만 선택하는 게 아쉽다", "내용 없는 블록 체크박스를 없애고 싶다")을 반영했다.

- **API:** `blockIds`를 없애고 `blockSelections: [{ noteId, blockIds }]`로 대체했다. `blockIds`는 feature 브랜치에만 있었고 호출부도 모달 하나뿐이었다.
  - 노트마다 전체/일부 블록을 섞어 선택할 수 있다.
  - 블록은 `(noteId, blockId)` 쌍으로 구분한다. 복사·붙여넣기로 두 노트에 같은 blockId가 있어도 섞이지 않는다.
  - `noteId`는 `noteIds`에 포함되어야 한다(소유권·강의 검증 우회 방지). 전체 블록은 최대 500개다.
  - 저장본에 없는 블록은 노트 제목을 넣은 400 메시지로 안내한다.
  - 로그에 `blockNoteCount`를 추가했다.
- **UI:** 전역 모드 토글을 없애고, 노트 트리 각 행의 "블록" 버튼으로 그 노트 아래에 블록 목록을 펼친다.
  - 노트 체크박스는 3상태다(해제/전체/일부 — indeterminate).
  - `전체`·`블록 N개`·`현재 노트` 배지를 붙이고, 블록 목록 왼쪽에 색 테두리를 둔다.
  - 하단에 선택 요약 칩("노트 제목 · 전체/블록 N개", ✕로 해제)을 둔다.
  - 다른 노트의 블록 목록은 한 번 불러와 캐시한다. 현재 노트는 펼칠 때마다 다시 불러온다.
  - 자동 저장 대기로 인한 생성 차단은 현재 노트의 블록을 골랐을 때만 적용한다.
- **빈 블록 제외:** 텍스트도 미디어(image·pdfBlock)도 없는 블록(빈 줄, 빈 제목 블록 등)은 블록 목록에서 뺀다. 텍스트 없는 이미지 블록은 "(내용 없음)" 대신 "(이미지)"로 표시한다.
- **구현 중 발견·수정:** `catch` 변수를 클로저에서 참조하는 코드 때문에 React Compiler가 모달 전체를 건너뛰어 hooks lint가 적용되지 않고 있었다(`react-hooks/invariant`로 확인). 메시지를 먼저 변수로 뽑아 해결했다.
- backend 243건, frontend 59건이 통과했다. 두 변경이 같은 파일에 섞여 있어 한 커밋으로 push했다.
