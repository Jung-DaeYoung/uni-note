## 1. 마이페이지 (`459da6f`)

- 학습 히트맵(왼쪽)과 전체 학습 통계(오른쪽)를 가로로 배치해 세로 공간을 줄였다(`lg:grid-cols-2`, 히트맵 칸 축소).
- 최근 활동은 5개씩 보여 주고, 아래 페이지 번호 버튼으로 넘긴다.

## 2. 이름 변경

### 퀴즈 (`4aca9ec`)

- `PUT /api/quiz/{quizSetId}` `{ title }`: 1~255자이고, 본인 퀴즈만 바꿀 수 있다. 응답은 204다.
- 경로 변수를 `{quizSetId:\d+}`로 제한했다. `PUT /api/quiz/generate`가 이 엔드포인트로 잡히지 않고 기존처럼 405를 받는다.
- 학습 보관함 퀴즈 목록에 연필 버튼을 추가했다.

### 오답노트 (`4b87e1d`)

- `PUT /api/quiz/incorrect/groups/{groupId}` `{ title }`: 1~255자이고, 앞뒤 공백을 지우고 저장한다.
  - 본인 오답노트만 바꿀 수 있다(아니면 403).
  - 본인의 다른 오답노트와 이름이 같으면 400 "같은 이름의 오답노트가 이미 있습니다."를 돌려준다. `(stud_id, title)` 유니크 제약 때문에 DB 오류(500)가 나기 전에 막는 것이다.
- 오답노트 모음 카드에서 이름 위 폴더 아이콘을 지우고, 이름 옆에 연필(이름 변경)과 휴지통(삭제) 버튼을 두었다.
- 다시 풀기 제목은 그룹 이름으로 매번 만들기 때문에 이름을 바꾸면 자동으로 따라 바뀐다.

## 3. 사이드바 (`52f135e`, `1c77ea8`, `1e124ea`)

최종 메뉴 순서는 다음과 같다.

1. 마이페이지
2. 강의목록
3. 나의 CBT 시험
4. 오답노트
5. 게시판(CBT 시험 공유게시판, 노트 공유 게시판)

- 강의를 누르면 그 강의의 노트 목록이 강의 메뉴 바로 아래에 나온다. 전에는 사이드바 맨 아래에 있었다.
- 강의목록은 대시보드·강의 페이지에서만, 게시판은 게시판 페이지에서만 펼친 채로 시작한다. 다른 페이지에서는 접혀 있다.

## 4. 설명 문구 정리 (`7f4df4c`)

- **지운 것:** 페이지 헤더 부제목(학습 보관함, 오답노트, 공유 게시판 2곳), 로그인 안내 문구, AI 문제 생성 모달의 부제목·문제 유형 설명·난이도 설명, 오답노트 저장 모달 부제목
- **남긴 것:** 동작을 알려 주는 안내
  - 블록 선택 힌트, 생성 모드 설명
  - 빈 목록 안내, AI 생성 고지
  - 자동 저장 2초·PDF·1문항 안내

## 5. 앱 알림·입력 창 (`ea6fd7c`)

- `ConfirmContext`를 넓혔다.
  - `hideCancel`: 확인 버튼 하나짜리 알림
  - `input: { defaultValue }`: 입력란이 있는 창. 저장하면 문자열, 취소하면 `null`을 돌려준다.
  - `notice` 스타일: 파란 정보 아이콘
- `showAlert(message)`를 export했다. Provider가 마운트되면 앱 창으로 동작하고, 그 전이나 Provider 없이 렌더링하는 테스트에서는 `window.alert`로 동작한다. `client.js`의 `registerLogoutHandler`와 같은 방식이다.
- 퀴즈·오답노트·강의 이름 변경 3곳을 앱 입력 창으로 바꿨다. 열리면 기존 이름이 선택돼 있고, Enter로 저장, ESC로 취소한다.
- `alert` 50곳을 `showAlert`로 바꿨다.
- **예외:** `api/client.js`의 403 알림은 바로 뒤에 페이지를 새로 불러온다. 앱 창으로 바꾸면 보이자마자 사라지므로 기본 alert를 유지했다.

## 6. 키워드 설명 (`3b98394`, `664f8bd`, `d974edb`)

### 텍스트 선택 메뉴

- 노트 배경과 색이 비슷해 잘 보이지 않던 "키워드 설명 | 문제 만들기" 메뉴를 어두운 색으로 바꿨다.
- 라이트 모드는 `slate-900`, 다크 모드는 `slate-700`에 테두리 `slate-500`이고, 글자는 흰색이다.

### 설명 패널

- 3줄 요약, 쉬운 설명, 전공 심화를 문장마다 줄을 바꿔 보여 준다. 마침표·물음표·느낌표 뒤 공백에서 나누고, `3.14`처럼 점 뒤에 공백이 없으면 나누지 않는다.
- 3줄 요약은 앞의 3문장까지만 보여 준다.
- '더 찾아보기' 카드에서 AI 추천 이유 문구를 숨겼다. API 필드 `reason`은 그대로 유지한다.

### 더 찾아보기 링크

- 허용 사이트를 한국어 위키백과와 Google 두 개로 줄였다. 영어 위키백과, MDN, Google Scholar는 뺐다.
- 첫 번째 자료는 위키백과로, 나머지는 서로 다른 관점의 Google 검색어로 고르도록 프롬프트를 바꿨다. 프롬프트 버전은 `2026-10-28.1`이다.
- 실제 Google 검색 결과를 가져오는 방식(Gemini 검색 연동)은 AI 호출이 1번 더 늘어나 비용과 지연이 생겨서 쓰지 않았다.
