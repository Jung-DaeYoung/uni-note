## 4. 통합 검색 (커밋 전)

계획은 `current-plan.md`와 `PLANS.md`(P1-7)에 있다(`1f4406c`).

### API

- `GET /api/search`: 파라미터는 `q`(2~100자), `type`, `courseId`, `page`, `size`다. 자세한 계약은 `docs/api.md`에 있다.
- `type`은 `all`, `note`, `post`, `shared_note`, `shared_quiz`다. `all`은 유형별 5개까지 돌려주고, `size`는 최대 50이다.
- 전체 개수를 세지 않고 `Slice`로 `hasMore`만 판단한다.
- 노트 결과는 노트당 1건이며, 일치한 첫 블록의 ID를 함께 준다.

### 권한 범위

- 노트는 본인 것만 검색하고, 직접 만든 강의의 노트도 포함한다.
- 게시판과 공유 글은 수강 중인 강의로 제한한다.
- 직접 만든 강의로 필터링하면 게시판·공유 결과는 오류 없이 비어 있다. 프론트엔드의 403 처리가 대시보드로 보내지 않게 하기 위해서다.
- 문제 공유는 공유된 퀴즈의 문항만 검색해 비공개 퀴즈가 노출되지 않게 했고, 해설은 검색하지 않는다.
- `LIKE`의 `%`, `_` 등 특수문자는 이스케이프한다.

### 화면

- 상단 헤더 검색창(`GlobalSearch`): 입력 250ms 뒤 검색하고, 이전 요청은 취소한다. 방향키·Enter·ESC 선택과 한글 조합 입력을 처리한다.
- 헤더 폭이 좁으면 입력창 대신 아이콘 버튼을 보여 준다. 사이드바에 따라 폭이 달라지므로 컨테이너 쿼리를 쓴다.
- 검색 화면(`/search`): 유형 탭, 강의 필터, 더 보기를 제공한다.
- 결과를 고르면 노트는 일치한 블록으로 스크롤해 강조하고, 게시글·공유 노트는 기존 화면으로 연다.
- 공유 시험은 `/shared-quizzes?sharedQuizId=`로 바로 연다. 강의 필터에 가려지지 않게 전체 목록에서 찾고, 처리 뒤 파라미터를 지운다.

## 5. 공통 확인창 (커밋 전)

- `ConfirmContext`에 Hallmark 디자인을 적용하고 `ConfirmContext.css`를 추가했다.
- 아이콘 타일, 둥근 카드, 그림자, 배경 흐림을 없앴다.
- 삭제 같은 위험 동작만 빨간 버튼이고, 공유·이동·알림은 기본 버튼 색으로 통일했다.
- 긴 문구는 창 안에서 스크롤되도록 높이를 화면의 90%로 제한했다.
- 호출 방식, ESC·닫기 동작, 위험 동작의 취소 버튼 포커스, 입력 기본값은 그대로다.
- 로그인 전에도 뜰 수 있어 `QuizLibraryPage.css`를 첫 로딩 번들에 포함했다.

## Hallmark 미적용 현황

라우트 페이지는 모두 적용했다. 오늘 공통 확인창을 끝냈고, 남은 것은 다음과 같다.

| 구분 | 대상 |
|---|---|
| 미적용 화면 | 풀이 기록 모달, 오답노트 모달, 문제별 댓글 |
| 일부만 적용 | 노트 화면 경로 표시와 빈 상태, 노트 편집 영역, 앱 헤더와 사이드바 로고·로그아웃 |
| 미적용 에디터 요소 | 블록 핸들, 코드 블록, PDF 블록, 페이지 링크, 키워드 선택 메뉴 |

추천 순서는 모달·댓글 → 경로 표시와 앱 헤더 → 편집 영역과 에디터 요소다. 에디터는 저장 형식과 편집 동작이 얽혀 회귀 위험이 가장 크다.
