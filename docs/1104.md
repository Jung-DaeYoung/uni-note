## 4. 설계 대비 확인사항

- Docker Compose는 사용하지 않는다. 설계 4장과 커밋된 구성은 단일 컨테이너 `docker run`이다.
- `t3.small`은 2GB이므로 EC2에서 이미지를 빌드하기 전에 swap 2GB를 추가한다.
- 0단계의 Netlify 사이트 주소가 아직 정해지지 않았다. `backend.env`의 `CORS_ALLOWED_ORIGINS`에 필요하므로 3단계 전에 확보한다.
- 8080 비공개는 보안 그룹 설정만 된 상태다. 컨테이너 실행 후 외부에서 접속되지 않는지 확인한다.
- Elastic IP는 연결 상태에서도 시간당 요금이 크레딧에서 차감된다. RDS 비용 산정 시 함께 계산하고 Billing 콘솔에서 잔액을 확인한다.
- 1103.md의 "리전 문서 미커밋"은 이후 `43ca1b8`로 커밋·push되었다. 이 커밋은 아직 `main`에 병합되지 않았다.
