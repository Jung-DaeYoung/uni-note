## 1. 학년·학기별 강의 목록

`docs/current-plan.md` 검토 후 사용자가 다음을 정했다.

- 학생은 스스로 수강 등록하지 않는다. 등록은 학교 시스템이 한다.
- 기준 학기는 4학년 2학기다.
- 기존 수강 강의는 4학년 1학기로 옮긴다.
- 4학년 2학기에는 캡스톤디자인Ⅱ, 소프트웨어공학, 자료구조와 알고리즘, 통계응용을 넣는다.
- 1~3학년 강의는 임의로 넣는다.

그래서 등록 API 없이 줄인 설계로 구현했다.

### 백엔드

- `domain/Enrollment.java`
  - `academicYear`(`academic_year`)와 `semester` 컬럼을 추가했다. 둘 다 NOT NULL이다.
  - `(stud_id, course_id)`에 유니크 제약을 걸었다. 강의 하나는 학생당 한 학기에만 둔다.
- `dto/CourseResponse.java`
  - `academicYear`, `semester` 필드를 추가했다. 직접 만든 강의는 `null`이다.
  - 기존 필드는 그대로라 기존 API와 호환된다.
- `service/DashboardService.java`: 수강 강의를 응답으로 바꿀 때 학년·학기를 채운다(`toCourseResponse(Enrollment)`).
- 테스트
  - `DashboardServiceTest`에 학년·학기 단언을 추가했다.
  - `SearchServiceIntegrationTest`는 수강 행을 만들 때 4학년 2학기 값을 넣도록 고쳤다.

### DB

- DDL과 시드 SQL은 `docs/database.md`에 적었다. 학번 자리는 `<학번>`으로 비워 두었다.
- 로컬 DB에만 적용했다. 대상은 학번 202104325의 수강 행이다.

| 학기 | 강의 |
|---|---|
| 1-1 | 컴퓨터개론, C프로그래밍, 대학수학 |
| 1-2 | 객체지향프로그래밍, 논리회로 |
| 2-1 | 자바프로그래밍, 컴퓨터구조, 선형대수 |
| 2-2 | 운영체제, 데이터베이스, 확률과통계 |

- **운영 RDS에는 아직 적용하지 않았다.** 운영은 `ddl-auto: validate`라서, 배포 전에 DDL과 시드를 먼저 실행해야 앱이 뜬다.
- 백엔드 테스트는 로컬 MySQL을 쓴다. 그래서 테스트를 돌리면 Hibernate가 `enrollments` 테이블을 바꾸고, 기존 행의 학년·학기를 0으로 채울 수 있다. 시드 SQL의 UPDATE는 NULL과 0을 모두 처리한다.

## 3. impeccable audit 1차 → 수정

1차 점수는 10/20이었다. 권장 항목을 하나씩 고쳤다.

- **번들 크기**: 코드 하이라이트 언어를 `all`에서 `common`으로 줄였다. 에디터 번들이 1.37MB에서 627KB로 줄었다.
- **모바일**
  - 사이드바는 768px 미만에서 서랍처럼 열린다. 배경 버튼, Esc 닫기, `inert`를 넣었다.
  - 높이는 `vh` 대신 `dvh`를 쓴다. 대상은 노트 화면, 게시판·키워드 패널, 검색이다.
  - 에디터 최소 높이와 여백은 화면 크기에 따라 달라진다.
- **접근성**
  - 이름 없던 입력칸에 이름을 달았다. 대상은 CBT 단답, 코드 언어 검색, 댓글 입력이다.
  - 메뉴 버튼에 `aria-expanded`를 달았다.
- **페이지 제목**: 경로별로 "X · UniNote" 형식이다(`App.jsx`의 `PageTitle`). 강의 페이지는 강의 이름을 쓴다. `index.html`은 `<title>`만 바꿨고 CSP는 그대로다.

## 6. 노트 헤더 버튼 (impeccable polish)

대상은 AI 문제 생성, 노트 공유, 커뮤니티 버튼이다. Hallmark로 만든 것을 다시 다듬었다(`CourseDetailPage.jsx/.css`).

- **바꾼 이유**: 세 버튼이 붙은 묶음이었는데, 이런 묶음은 "하나를 고르는" 컨트롤로 읽힌다. 실제로는 서로 다른 동작이라 각각 떨어진 `lib-btn`으로 바꿨다.
- **AI 문제 생성**: 이 화면의 주 동작이라 혼자만 색을 채운 버튼(`lib-btn-primary`)으로 했다.
- **커뮤니티**
  - 열면 이름이 "닫기"로 바뀌던 것을 "커뮤니티"로 고정했다.
  - 열린 상태는 파란 테두리·글자와 옅은 배경으로 보여 준다.
  - 화면 낭독기에는 `aria-expanded`로 열림 여부를 알린다.
- **비활성 버튼**: 마우스를 올려도 배경이 바뀌지 않게 했다.
- **그대로 둔 것**: 버튼 순서, 문구, 좁은 화면에서 앞 낱말("AI", "노트")을 숨기는 동작.

## 확인하지 못한 것 / 남은 일

- **화면에서 보지 못한 컴포넌트**: PDF 블록, 코드 언어 선택, 블록 메뉴, 업로드 상태. 블록을 넣으면 자동 저장으로 실제 노트가 바뀌기 때문이다. 테스트용 노트에서 확인이 필요하다.
- **스크린샷 시간 초과**: 에디터가 있는 페이지는 스크린샷이 계속 시간 초과로 실패한다. 그래서 수치로만 확인했다. 원인은 모른다.
- **모바일 에디터 위 여백**: 16px뿐이라 업로드 상태 줄 윗부분이 살짝 가려질 수 있다.
- **블록 핸들**: 터치로 끌기는 확인하지 않았다.
- **운영 RDS**: 학년·학기 DDL과 시드를 적용해야 한다.
- **커밋**: 아직 하지 않았다. 학기 기능, 스킬 설정, audit 수정, 디자인 정리로 나눠 커밋하는 것을 제안한다.
