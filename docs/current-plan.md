# 키워드 설명 노트 적용 확인 (키워드 학습 패널 3단계 보완)

## 문제와 목표

지금은 패널의 "노트에 삽입"을 누르면 확인 없이 바로 노트가 바뀐다. 무엇이 어디에 들어갈지 미리 보고, 사용자가 적용할지 정한 뒤에만 넣도록 바꾼다.

키워드 통계(PLANS.md 4단계)는 만들지 않는다. 대신 기존 오답노트의 "취약 개념" 카드를 쓴다. 이 결정은 PLANS.md에 반영했다.

## 변경

- 패널 버튼 이름을 "노트에 적용"으로 바꾸고, 완료 안내도 "노트에 적용했습니다"로 바꾼다.
- 버튼을 누르면 공통 확인 모달(`ConfirmContext`의 `useConfirm`)을 연다. 새 모달은 만들지 않는다.
  - 제목: "설명을 노트에 적용할까요?"
  - 메시지: 선택한 블록 바로 아래에 인용 블록으로 들어간다는 안내와, 실제로 넣을 문단을 그대로 미리 보여 준다.
  - 버튼: "적용" / "적용 안 함", variant는 `share`(파란색)를 쓴다.
  - "적용"을 고를 때만 삽입한다. 취소, ESC, 닫기는 아무것도 바꾸지 않는다.
- 미리보기와 실제 삽입이 어긋나지 않도록, 넣을 문단 목록을 `insertKeywordExplanation.js`의 `explanationParagraphs`로 한 번만 만들어 둘 다 쓴다.
- `CourseDetailPage.insertExplanation`은 async로 바꾸고 확인 결과에 따라 true/false를 돌려준다. 패널은 결과를 기다린 뒤 완료 안내를 띄운다.

## 검증

- **vitest:**
  - `explanationParagraphs`: 문단을 나누는 규칙
  - 패널: 버튼 이름, `onInsert` 결과가 false면 완료 안내를 띄우지 않음
- `npm run lint`, `npm run build`, `npm run test`
- **브라우저:** 적용 안 함이면 노트가 그대로이고, 적용이면 인용 블록이 들어가 자동 저장되는지 확인한다.
