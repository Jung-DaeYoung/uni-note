# UniNote 신규 기능 추천 및 개발 우선순위

## 1. 판단 기준

신규 기능은 다음 기준으로 평가한다.

- 실제 사용자에게 유용한가
- 현재 UniNote 기능과 자연스럽게 연결되는가
- 기존 코드·DB를 재사용해 구현할 수 있는가
- 캡스톤 프로젝트의 완성도와 차별성을 높이는가
- 개발 비용과 복잡도가 적절한가

현재 UniNote의 핵심 학습 흐름은 다음과 같다.

```text
강의 수강
→ 계층형 노트 작성
→ AI 퀴즈 생성
→ 퀴즈 풀이·서버 채점
→ 오답노트 저장
→ 오답 재풀이
```

신규 기능은 이 흐름을 확장하는 방향을 우선한다.

## 2. 전체 추천 우선순위

| 순위 | 기능 | 예상 난이도 | 핵심 가치 |
|---:|---|---|---|
| 1 | 스마트 오답 복습·취약 개념 리포트 | 중간 | 기존 풀이 데이터를 활용해 사용자가 다시 공부할 내용을 알려준다. |
| 2 | 오답 간격 반복 복습 | 중간 | 오답을 일정 주기로 다시 풀게 해 실제 학습 효과를 높인다. |
| 3 | 강의별 학습 리포트·활동 히트맵 | 중간 | 대시보드 요구사항을 완성하고 학습 활동을 시각화한다. |
| 4 | 출처 기반 AI 요약·핵심 개념 카드 | 중간 | 노트·AI·오답 흐름을 연결하고 UniNote의 차별성을 강화한다. |
| 5 | 노트 전문 검색 | 낮음~중간 | 기존 `searchContent`를 활용해 필요한 노트를 빠르게 찾는다. |
| 6 | 퀴즈 이어풀기 | 낮음~중간 | 중단한 퀴즈를 이어서 풀어 사용성을 높인다. |
| 7 | 오답 문제별 개인 메모 | 낮음~중간 | 오답 원인과 기억할 내용을 직접 기록할 수 있게 한다. |
| 8 | 게시판 좋아요·공감·질문 해결 표시 | 중간 | 익명 커뮤니티의 참여도를 높인다. |
| 9 | 노트 버전 히스토리·복원 | 중간~상 | 자동 저장으로 인한 실수나 삭제를 복구할 수 있게 한다. |
| 10 | 협업 노트·공유 퀴즈 | 높음 | 차별성은 높지만 권한·동시 편집·데이터 구조 변경이 크다. |

## 3. 1순위: 스마트 오답 복습·취약 개념 리포트

### 추천 이유

현재 UniNote에는 이미 다음 데이터가 저장된다.

- `QuizAttempt`: 퀴즈 풀이 기록과 점수
- `UserAnswer`: 문제별 제출 답안과 정답 여부
- `Question`: 문제 유형, 정답, 해설, 원본 노트·블록 출처
- `IncorrectNoteItem`: 사용자가 저장한 오답 문제
- `QuizSet`: 강의와 퀴즈 생성 노트 정보

따라서 새로운 대규모 데이터 모델 없이도 반복 오답, 최근 오답, 강의별 정답률을 계산할 수 있다. 기존 오답노트를 단순 저장소가 아니라 다음 학습 행동을 제시하는 기능으로 확장할 수 있다는 점에서 가장 우선순위가 높다.

### 1차 구현 범위

- 강의별 평균 점수
- 문제 유형별 정답률
- 문제별 오답 횟수
- 반복해서 틀린 문제
- 최근 틀린 문제
- 오늘 복습할 문제 목록
- 오답 문제의 원본 노트·블록 이동
- 오답 재풀이 진입

### 2차 AI 확장

- 반복 오답의 공통 개념 분석
- 오답 원인 설명
- 취약 개념 요약
- 원본 노트 기반 복습 가이드
- 다음 학습 노트 추천

### 기존 기능 연결

```text
QuizAttempt + UserAnswer
→ 오답 횟수·최근 풀이·정답률 집계
→ Question 및 IncorrectNoteItem 연결
→ sourceNoteId/sourceBlockId로 원본 노트 이동
→ 기존 오답 재풀이 화면 재사용
```

### 예상 난이도

**중간**

- 통계와 복습 목록: 중하
- 복습 주기와 상태 저장: 중간
- AI 취약 개념 분석: 중상

처음부터 AI에 의존하지 않고 규칙 기반 분석을 먼저 구현한 뒤, AI는 설명과 요약을 보조하는 방식으로 추가한다.

## 4. 2순위: 오답 간격 반복 복습

오답 문제를 저장하는 것에서 끝내지 않고, 적절한 시점에 다시 풀도록 관리한다.

### 예상 데이터

- `lastReviewedAt`
- `nextReviewAt`
- `reviewCount`
- `interval`
- `lastReviewCorrect`

### 초기 복습 규칙 예시

```text
첫 오답: 1일 후
두 번째 오답: 3일 후
세 번째 오답: 7일 후
반복 오답: 복습 주기 단축
```

### 추천 이유

- 기존 오답 그룹과 재풀이 API를 재사용할 수 있다.
- 외부 AI 없이도 학습 서비스다운 기능을 제공할 수 있다.
- 1순위 스마트 오답 복습의 자연스러운 확장이다.

## 5. 3순위: 강의별 학습 리포트·활동 히트맵

### 표시 대상

- 노트 수정 횟수
- 퀴즈 풀이 횟수
- 게시글·댓글 작성 수
- 날짜별 전체 학습 활동
- 강의별 학습량
- 최근 오답 및 복습 완료 현황

### 추천 이유

활동 히트맵은 요구사항 문서에 이미 포함되어 있으나 현재 실제 대시보드에는 구현되지 않았다. 대시보드의 시각적 완성도를 크게 높일 수 있다.

### 주의점

현재 별도 활동 로그 엔티티가 없으므로 초기 버전은 `Note.updatedAt`, `Post.createdAt`, `Comment.createdAt`, `QuizAttempt.startTime`을 기준으로 집계한다. 이후 활동 종류가 늘어나면 통합 활동 로그 테이블을 검토한다.

## 6. 4순위: 출처 기반 AI 요약·핵심 개념 카드

단순한 긴 글 요약보다 다음 정보까지 함께 제공하는 방향을 추천한다.

- 핵심 개념
- 시험에 나올 수 있는 포인트
- 원본 노트 블록 링크
- 관련 퀴즈 문제
- 관련 오답 문제

현재 Tiptap 콘텐츠 추출과 AI 퀴즈 생성 기반을 재사용할 수 있다. 요약 결과에도 노트·블록 출처를 유지하면 AI 퀴즈와 구별되는 학습 자료가 된다.

## 7. 5순위: 노트 전문 검색

### 구현 범위

- 로그인한 학생의 노트만 검색
- 강의별 검색 범위 선택
- 제목·`searchContent` 검색
- 결과에 노트 제목·강의·수정 시각·미리보기 표시
- 결과 클릭 시 해당 노트로 이동

### 추천 이유

자동 저장 시 이미 `searchContent`가 저장되므로 데이터 모델 변경 부담이 작다. 구현 난이도 대비 사용자 효용이 높지만, 일반적인 검색 기능이므로 캡스톤 차별성은 오답 분석보다 낮다.

## 8. 6~7순위: 완성도 개선 기능

### 퀴즈 이어풀기

`QuizStatus.IN_PROGRESS`와 기존 풀이 데이터를 활용해 다음을 제공한다.

- 문제별 임시 답안 저장
- 현재 문제 위치 저장
- 진행률 표시
- 중단한 퀴즈 이어풀기

### 오답 문제별 개인 메모

오답 문제에 다음 메모를 저장한다.

- 왜 틀렸는지
- 기억해야 할 개념
- 보충 설명
- 다시 확인할 원본 노트

오답노트의 학습 가치를 높이는 기능이며, 기본 오답 통계 이후 추가하는 것이 적절하다.

## 9. 8순위 이후 기능

### 게시판 좋아요·공감·질문 해결 표시

요구사항에는 포함되어 있지만 현재 `Like` 엔티티·Repository·API가 없다. 사용자별 중복 공감 방지와 게시글 응답 확장이 필요하다. 커뮤니티 참여를 높일 수 있으나 UniNote의 핵심 학습 루프와 직접적인 연결은 상대적으로 약하다.

### 노트 버전 히스토리·복원

자동 저장 실수와 데이터 손실을 복구할 수 있어 유용하지만, 저장할 때마다 버전을 만들면 데이터가 빠르게 늘어난다. 일정 시간 간격·수동 저장·변경량 기준을 먼저 정해야 한다.

### 협업 노트·공유 퀴즈

차별성은 높지만 개인 소유 노트 구조와 충돌한다. 공유 권한, 편집 권한, 동시 편집 충돌, 익명성 정책이 필요하므로 현재 우선순위에서는 제외한다.

## 10. 권장 전체 개발 순서

```text
1. 오답 문제 소유권 검증 보완
2. 오답 그룹 내부 문제 조회·삭제 UI
3. 문제별 오답 횟수와 최근 풀이 통계
4. 강의별 취약 문제·취약 유형 리포트
5. 오늘의 복습 목록
6. 오답 재풀이 결과 반영
7. 간격 반복 복습
8. AI 오답 분석과 취약 개념 요약
9. 대시보드 학습 리포트·활동 히트맵
10. 노트 검색
11. 출처 기반 AI 요약·핵심 개념 카드
12. 퀴즈 이어풀기·오답 메모
13. 게시판 공감
14. 노트 버전 히스토리
15. 협업 기능
```

## 11. 최종 추천

가장 먼저 개발할 기능은 **출처 기반 스마트 오답 복습 시스템**이다.

```text
오답 통계
→ 오늘의 복습 목록
→ 취약 개념 리포트
→ AI 오답 분석
→ 간격 반복 복습
→ 대시보드 학습 리포트·히트맵
```

이 순서는 기존 코드와 DB를 최대한 재사용하면서, UniNote의 핵심 차별점인 다음 흐름을 강화한다.

> 개인 강의 노트 → 출처가 있는 AI 평가 → 오답 기반 재학습

야간모드는 학습 기능 자체보다는 사용성·완성도 개선 기능이므로, 핵심 학습 기능 개발과 병행하되 위 기능들보다 우선순위를 높이지 않는다.
