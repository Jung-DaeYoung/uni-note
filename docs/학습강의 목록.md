# 📚 UniNote 코드 과외 커리큘럼 및 진행 현황

이 문서는 UniNote 프로젝트의 전체 아키텍처와 기능을 체계적으로 학습하기 위한 전체 강의 커리큘럼입니다.  
사용자 행동(Frontend)부터 백엔드 API, 서비스 비즈니스 로직, 데이터베이스(JPA/MySQL)까지 이어지는 데이터 흐름과 설계 의도를 단계별로 다룹니다.

---

## 📌 진행 현황 요약
- **총 강의 수**: 10강
- **완료된 강의**: 1강 ~ 10강 (100% 완강 🎉)
- **남은 강의**: 없음 (전체 커리큘럼 완료)

---

## 🟢 완료된 강의 목록

### ✅ [1강: 로그인 & JWT 인증 (Authentication)](./lecture-01-authentication.md)
- **주요 내용**: 학번/비밀번호 로그인, BCrypt 해싱, JWT 생성 및 유효성 검증, Axios Request Interceptor를 통한 토큰 자동 주입, `JwtFilter`와 Spring Security `SecurityContextHolder`, `ProtectedRoute` 라우트 보호.
- **핵심 파일**: `LoginPage.jsx`, `AuthContext.jsx`, `client.js`, `AuthController.java`, `AuthService.java`, `JwtUtil.java`, `JwtFilter.java`.

### ✅ [2강: 대시보드 (Dashboard)](./lecture-02-dashboard.md)
- **주요 내용**: 학습 허브 홈 화면, `CourseContext`를 통한 단일 집약 API 캐싱, 수강 강의 목록/최근 수정 노트 6개/수강 과목 최신 게시글 5개 통합 조회, 미수강 과목 게시글 격리 보안, JPA `readOnly = true` 최적화.
- **핵심 파일**: `DashboardPage.jsx`, `CourseContext.jsx`, `AppLayout.jsx`, `DashboardController.java`, `DashboardService.java`.

### ✅ [3강: 계층형 노트 트리 (Note Tree)와 노트 생성/조회](./lecture-03-note-tree.md)
- **주요 내용**: Notion 스타일 자기참조(Self-referencing) 엔티티 모델링, N+1 쿼리를 방지하는 1회 일괄 조회 및 메모리 Map 트리 조립 알고리즘, 부모 삭제 시 연쇄 삭제(`orphanRemoval`), 브레드크럼 역추적, 초기 Tiptap JSON 주입.
- **핵심 파일**: `useCourseNotes.js`, `NoteTreeContext.jsx`, `NoteTreeItem.jsx`, `Note.java`, `NoteController.java`, `NoteService.java`.

### ✅ [4강: Tiptap 에디터 편집, 자동 저장 (Autosave) & 로컬 복구](./lecture-04-tiptap-autosave.md)
- **주요 내용**: React Tiptap 블록 에디터 연동 및 JSON 데이터 구조, `useNoteAutosave` 훅의 2단계 디바운스(로컬 300ms vs 서버 2000ms), `localStorage` 타임스탬프 기반 자동 복구, `AbortController`를 통한 빠른 노트 전환 시 레이스 컨디션 방지, 헤더 저장 상태 머신(`Synced / Saving / Error / Retry`).
- **핵심 파일**: `NotionEditor.jsx`, `useNoteAutosave.js`, `CourseDetailPage.jsx`, `NoteController.java`, `NoteService.java`, `NoteRequest.java`.

### ✅ [5강: Slash Command (/) 메뉴 및 커스텀 에디터 확장 블록](./lecture-05-slash-command.md)
- **주요 내용**: Tiptap Extension 및 Suggestion 플러그인 연동, Tippy.js를 활용한 커서 위치 기반 플로팅 팝업, `priority: 1000`을 통한 키보드 충돌 해결, 하위 노트 생성 및 최신 제목 실시간 반영 `PageLink` 블록, AI 퀴즈 출처 추적을 위한 `BlockId` 전역 확장.
- **핵심 파일**: `SlashCommand.js`, `SuggestionList.jsx`, `BlockId.js`, `PageLink.jsx`, `NotionEditor.jsx`.

### ✅ [6강: 파일 업로드 (이미지 & PDF) 및 보안 서빙 (Magic Bytes & 서명 URL)](./lecture-06-file-upload.md)
- **주요 내용**: 클라이언트 1차 확장자/10MB 사전 검증, 백엔드 매직 바이트(Magic Bytes) 바이너리 시그니처 위장 파일 차단, UUID 파일명 치환 및 `normalize()` 기반 경로 조작(Path Traversal) 공격 방어, 브라우저 `<img>` 및 다운로드를 위한 `FileAccessSigner` HMAC-SHA256 서명 URL 발급과 403 인가 통제.
- **핵심 파일**: `ImageUploadController.java`, `FileAccessSigner.java`, `useNoteUploads.js`, `PdfBlock.jsx`, `NotionEditor.jsx`.

### ✅ [7강: 강의 커뮤니티 익명 게시판 & 댓글 시스템](./lecture-07-community-board.md)
- **주요 내용**: 강의별 익명 게시글 및 댓글 CRUD, `validateEnrollment` 수강생 인가 격리, DB 학번을 클라이언트에 노출하지 않고 일관된 가명(`studId % 100`) 및 `isAuthor` 플래그를 산출하는 DTO 변환 알고리즘, 부모 글 삭제 시 댓글 자동 연쇄 삭제(`orphanRemoval`), 대시보드 `postId` 딥링크 연동.
- **핵심 파일**: `PostController.java`, `PostService.java`, `Post.java`, `Comment.java`, `CourseBoardPanel.jsx`, `useCourseBoard.js`.

### ✅ [8강: AI 기반 퀴즈 자동 생성 파이프라인](./lecture-08-ai-quiz-generation.md)
- **주요 내용**: `QuizConfigModal` 계층 트리 선택, 백엔드 상한선 통제(노트 20개/문제 30개), Tiptap 본문 파싱 및 `[[REF:noteId/blockId]]` 출처 태그 주입, 첨부 파일 서명 검증 및 멀티모달 Base64 전송, Google Gemini 2.5 Flash Structured Outputs(JSON Schema) 연동, `QuizSet` 및 `Question` 영속화.
- **핵심 파일**: `QuizController.java`, `QuizService.java`, `QuizAiGenerationService.java`, `QuizSet.java`, `Question.java`, `QuizConfigModal.jsx`.

### ✅ [9강: CBT 퀴즈 풀이, 서버 채점 & 오답노트 기초](./lecture-09-cbt-quiz-grading.md)
- **주요 내용**: 1문항 집중형 CBT 인터페이스(`CBTPlayer`), 클라이언트 점수를 신뢰하지 않는 서버 주도 채점(`saveAttempt`), 공백/대소문자 무시 정규화 판정(`isAnswerCorrect`), 가상 세션(`quizSetId: -1L`) 기반 오답 재풀이, 출처 블록 ID를 통한 원본 필기 문단 스크롤 점프, 오답노트 그룹화(`IncorrectNoteGroup`).
- **핵심 파일**: `QuizController.java`, `QuizService.java`, `IncorrectNoteService.java`, `QuizAttempt.java`, `UserAnswer.java`, `CBTPlayer.jsx`, `IncorrectNoteModal.jsx`.

### ✅ [10강: 스마트 오답 복습, 취약 개념 분석 & 프론트 테마 시스템](./lecture-10-smart-review-analysis.md)
- **주요 내용**: `UserAnswerRepository`의 GROUP BY 단일 집계 프로젝션(`QuestionAnswerStat`)을 통한 데이터 일관성 및 DB 최적화, 규칙 기반(반복 오답/정답률 < 50%) 복습 우선순위(HIGH/MEDIUM/LOW) 산출 공식, "오늘의 복습" 추천 큐, Tailwind v4 다크모드(`ThemeContext`, `localStorage`, `storage` 브로드캐스트 이벤트 다중 탭 동기화), 1~10강 전체 풀스택 아키텍처 총정리.
- **핵심 파일**: `UserAnswerRepository.java`, `QuestionAnswerStat.java`, `IncorrectNoteService.java`, `IncorrectNoteController.java`, `ThemeContext.jsx`, `QuizLibraryPage.jsx`.

UniNote의 전체 10강 과외 커리큘럼이 모두 작성되었습니다.  
인증부터 에디터, 파일 보안, 익명 게시판, AI 문제 출제, CBT 채점, 취약점 분석 및 테마 시스템까지 풀스택 웹 애플리케이션의 핵심 라이프사이클을 체계적으로 학습할 수 있습니다.
